# Password Strength Checker

## Project Description
A simple Python-based Password Strength Checker developed as part of the SkillCraft Technology Cybersecurity Internship.

The program evaluates password strength based on five criteria and classifies it as Weak, Moderate, or Strong.

## Features
- Checks password length.
- Detects uppercase letters.
- Detects lowercase letters.
- Identifies numerical digits.
- Detects special characters.
- Displays password strength based on the criteria met.

## Technologies Used
- Python 3
- VS Code

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python password_checker.py
```

4. Enter a password when prompted.

## Learning Outcomes
- Python conditional statements.
- String manipulation.
- Character validation.
- Basic password security concepts.

## Disclaimer
This is an educational project and does not provide a complete assessment of password security.
